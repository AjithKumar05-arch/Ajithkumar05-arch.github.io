My Fourth Reflection-Blog

May 8, 2026

Introduction

I welcome you back in my fourth reflection blog of Unit 4. The Unit 4 was project based unit and was named ‘Projects on Communicating Information’. There were two small but interesting projects under it. The first one was creating a chatbot using typeboat and the second one was developing a dashboard using metabase. In this reflection blog, I will talk about the challenges, learnings and experiences I had while doing both of them. So stay tunned and we will walk through it together.

A small brief about the projects

ChatBot- It is conversational interface created using typebot. It acts as a virtual assitant which provides answers to the user related to a specific topic. Typebot is an open source tool used create conversational bots like chatbot for apps and websites.

Dashboard- It is a tool which helps us to display various types of visual charts at one place. For my project, I created dashboard using Metabase. Metabase is an open source tool used to create various types of visual charts.

Challenges and Difficulties

The biggest challenge for me while doing the project was its newness. I was a complete beginner to the tools like typebot and metabase. So firt I had to learn them and then work on them. For learning purpose I took help from Google and chat gpt. Once I got to know the basic idea of how they work I started working on them.

Typebot- When I started working on typebot, I learnt about the sections like texts and buttons through google and chatgpt but didn’t know how to use them. I single clicked on them, double clicked on them but things did not work out. Then finally after a lot of time I learnt that we have to drag and drop them. I did that and it happend. But after this also the iterface did not run. The problem was that different sections had to be connected together and I didn’t know. This time I asked about this problem to Sidharth and he helped me out. After knowing this two things, working on it became easier and I did the rest of the part easily.

Metbase- Metabase threw a lot of problem on me while I worked on it. The firt problem was to understand it. At first it seemed very complicatdd but as I put my time and effort on it, it became easy. I faced difficulties with simple things like add question, summarise, group by, add column and so on. But as I kept working on it, as I kept making mistakes, I learned about it nicely and thus moved ahead. After spending some good amount of time, I finished this project also.

Some key Learnings

  1. Ask for help whenever necessary- This is one of the key learnings that I had while doing the projects. When I faced problem in running the chatbot interface, I asked Sidharth for help and he knew the solution for problem so the problem was immediately sorted out. This thing remind me of one of the famous saying from bible “He who seeketh findeth. And to those who knocketh, the door shall be opened. Now I firmly believe in this.
  2. Practice makes a man perfect- I realised this after I was done with the metabase project. At the intial phase of prject, it seemed me very complicated. But as I kept working on it, as I kept making mistakes and correcting them, it became really simple tool. So yeah “Practice makes a man perfect”.
  3. Working together is fun- Metabase project was sort of group project. We were five members who collectively work on it. We had a lot of disscusions about the project together which included fun talks as well. When you work in group, the work just happen smoothely without you being realising about it.

Conclusion

Working on both the projects under unit 4 was amalgamation of both kind of experiences- good and bad. I faced some major challenges but then I also learnt some major lessons. Now when I have reflected back on them, I must thank our Instructor Bhanu Priya S who made the learning journey interesting and enjoyable. She tried hard to make us work in groups and she succeded also. I would like to thank my groupmates and classmates who were always ready to help me when I found difficulties. They made the class environment very vivrant with their energies. Also I would like to thank myself who never gave up no matter what. That is it. Thank you.
